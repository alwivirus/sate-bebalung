# TUGAS PRAKTIK DATABASE - DEPOT SATE BE BA LUNG
**Program Keahlian:** Rekayasa Perangkat Lunak (RPL)  
**Kelompok / Tugas:** Tugas 5 - Database Engineer & Architect

---

## 📂 Struktur Isi Folder Tugas Ini:

1. **`Dokumentasi_Laporan/`**
   - `Laporan_Praktik_Database_V1_sampai_V3.md` : Catatan kronologis proses pembuatan dari awal sampai selesai.
   - `Diagram_ERD_dan_Struktur_Tabel.md` : Gambar diagram relasi tabel dan penjelasan kolom.
   - `Cara_Pemasangan_Database.md` : Panduan praktis cara import database ke phpMyAdmin atau jalankan migrate seed.

2. **`Versi_1_Awal/`**
   - Berisi file SQL dump dan migrasi awal (5 tabel utama: users, categories, menus, orders, order_items).

3. **`Versi_2_Tambah_Meja_dan_Setting/`**
   - Berisi file SQL dump dan migrasi versi revisi (+ tabel tables untuk scan QR meja, tabel settings untuk rekening QRIS resto, dan penambahan role admin/kasir/dapur/owner).

4. **`Versi_3_Final_Siap_Pakai/`**
   - Berisi file SQL dump final (`database_bebalung_v3_final.sql`), 7 file migration, 5 file seeder, dan 7 model Eloquent lengkap yang siap dipakai di lokal maupun hosting.

---

## 🚀 Cara Cepat Pakai:
Buka `Dokumentasi_Laporan/Cara_Pemasangan_Database.md` untuk panduan import file `database_bebalung_v3_final.sql` ke database MySQL Anda.
